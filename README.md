# Лабораторная работа № 2. Блоговая платформа

Учебный интерфейс блога на React (вариант 4). Компоненты повторяют макет из лабораторной работы № 1: логотип, карточка статьи, кнопки Post, Like и Comment, поле комментария.

## Запуск

```bash
cd "/Users/anisya/Desktop/7 сем/инис/lab2"
npm install
npm run dev
```

После запуска откройте адрес из терминала, обычно http://localhost:5173.

## Компоненты

- `LikeButton` — счётчик лайков в `useState`, значение увеличивается по клику.
- `ArticleCard` — заголовок, автор, дата, текст и изображение приходят через `props`.
- `CommentInput` — текст комментария хранится в `useState` и обновляется через `onChange`.
